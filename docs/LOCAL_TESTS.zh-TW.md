## 實際執行的內容

示範程式建立虛擬房間，繪製八張小型 PINHOLE 影像，提供已知相機／rig 軌跡，
並產生帶時間戳的合成 LiDAR 點。處理程式再將照片與這條軌跡配對、重播點雲，
匯出 COLMAP 初始化資料；沒有使用 SLAM 估計軌跡。

## 這些檢查尚未證明的能力

- MAX2 擷取，或任何移動、長時間的 LiDAR 擷取。
- 偵測實體未同步錄製（僅以模擬驅動時間戳測試）。
- 真正的即時 SLAM、閉環或實測即時吞吐量。
- MAX2 曝光同步及真正的支架外參校正。
- 原始 .360／EAC 解碼及真實 MAX2 拼接全景的轉換。
- 全景視角中的 rolling shutter、拼接視差或遮罩。
- 真實室內外幾何精度。
- 3DGS 訓練、畫質或各訓練器特定相容性。
- 實體手機操作、感測器熱狀態及可攜電源續航。

ROS 記錄器使用建構的訊息測試，尚未連接執行中的 ROS graph。
後續實機驗收請見[開發路線](ROADMAP.zh-TW.md)。

## 在本機重現

安裝專案後：

    python -m unittest discover -s tests -v
    python tools/smoke.py
    python tools/check_project.py

全景測試與 smoke 的全景步驟需要 PATH 中有 ffmpeg 與 ffprobe；
若沒有，轉換測試會略過，smoke 報告也會註明。

選用的瀏覽器檢查需要 dev 額外套件及本機 Chrome／Chromium：

    python -m pip install -e '.[dev]'
    python tools/check_viewer.py runs/replay/preview.html

檢查器也接受 --browser 指定相容的瀏覽器執行檔。
測試會建立新的暫存掃描，不修改已有資料。
