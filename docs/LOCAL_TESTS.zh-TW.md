# 本機測試紀錄

[English](LOCAL_TESTS.md) | **繁體中文**

日期：2026-11-11。本次為本機軟體檢查，沒有連接 MAX2 或 MID-360，
沒有將儲存庫或掃描資料發布到 GitHub。

## 實際執行的內容

示範程式建立虛擬房間，繪製八張小型 PINHOLE 影像，提供已知相機／rig 軌跡，
並產生帶時間戳的合成 LiDAR 點。處理程式再將照片與這條軌跡配對、重播點雲，
匯出 COLMAP 初始化資料；沒有使用 SLAM 估計軌跡。

| 檢查 | 結果 |
| --- | --- |
| 幾何、時間、匯出與 ROS 訊息轉換 | 28 項單元測試通過 |
| Python 執行環境 | Python 3.12 與 3.14 均通過單元測試及 CLI 完整流程 |
| CLI 完整流程 | 示範 → 驗證 → 重播 → 匯出及時鐘擬合通過 |
| 套件發行檔 | 成功建立 wheel，在乾淨環境安裝後不需執行期相依套件即可通過 CLI 完整流程 |
| 示範資料 | 8 張影像、165 筆位姿、17,280 個原始點；0.05 m 體素減為 14,806 點 |
| COLMAP 原生讀取 | 讀入 8 張已註冊影像及 14,806 個點 |
| 觀測軌跡 | 刻意為零，這是初始化模型 |
| 瀏覽器 | 檢查桌面 1280×900 及窄版 390×844 |
| 預覽控制 | 滑鼠／鍵盤旋轉、滾輪縮放、相機切換及重設通過 |
| 離線預覽 | 沒有對外 HTTP(S) 請求或瀏覽器程式錯誤 |
| 文件 | 檢查本機連結、雙語對應及原始碼語法 |
| 專案技能 | 技能格式驗證通過 |

COLMAP 為 4.3.0.dev0、commit 3c1a1b95；瀏覽器使用 headless Google
Chrome 151.0.7922.137。合成投影測試使用獨立的解析座標。
原生讀取器在沒有觀測時顯示的重投影數字，不能當成精度量測。

已準備的 CI 設定包含 Python 3.10，但本機沒有此版本；本階段尚未執行
該版本或遠端 CI。

## 這些檢查尚未證明的能力

- 實體裝置搜尋、控制或擷取。
- 真正的即時 SLAM、閉環或實測即時吞吐量。
- MAX2 曝光同步及真正的支架外參校正。
- 原始 .360 解碼與全景視角產生。
- 真實室內外幾何精度。
- 3DGS 訓練、畫質或各訓練器特定相容性。
- 實體手機操作、感測器熱狀態及可攜電源續航。

ROS 記錄器使用建構的訊息測試，尚未連接執行中的 ROS graph。
後續實機驗收請見[開發路線](ROADMAP.zh-TW.md)。

## 在本機重現

安裝專案後：

    python -m unittest discover -s tests -v
    python tools/smoke.py
    python tools/check_project.py

選用的瀏覽器檢查需要 dev 額外套件及本機 Chrome／Chromium：

    python -m pip install -e '.[dev]'
    python tools/check_viewer.py runs/replay/preview.html

檢查器也接受 --browser 指定相容的瀏覽器執行檔。
測試會建立新的暫存掃描，不修改已有資料。
